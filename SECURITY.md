# 🔒 Security Policy

The security of the **Credit Card Approval Prediction System** is taken very seriously. We appreciate your efforts to responsibly disclose your findings, and we will make every effort to acknowledge your contributions.

---

## 🛡️ Supported Versions

We currently provide security updates to the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not** open a public issue. Doing so puts the community and users at risk before a patch can be developed.

Instead, please report the vulnerability privately by reaching out:

- **Maintainer**: 𝕊𝕦𝕟𝕚𝕝 𝕊𝕙𝕒𝕣𝕞𝕒
- **LinkedIn**: [Sunil Kumar](https://www.linkedin.com/in/sunil-kumar-bb88bb31a/)
- **GitHub**: [@sunbyte16](https://github.com/sunbyte16)

### When submitting a report, please include:
1. **Description**: Details explaining the vulnerability.
2. **Steps to Reproduce**: Minimal reproducible example or proof-of-concept (PoC).
3. **Impact**: An assessment of the attack surface, severity, and potential impact.
4. **Remediation**: Any suggestions or pull requests for mitigating the vulnerability.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to analyze and remediate the issue promptly.
